Hero video drop-in folder
=========================

Place the two video files here with these exact names:

  public/assets/hero-wide.mp4      (desktop / >= 768px wide)
  public/assets/hero-vertical.mp4  (mobile / < 768px wide)

Vite copies this folder to dist/assets on build, so the page references
./assets/hero-wide.mp4 and ./assets/hero-vertical.mp4 with no code changes.

Both files are generated by the site owner in the brief: generic burger
grilling footage, ILLUSTRATIVE ONLY. The hero always shows a visible
"Illustrative video" badge and must never imply the footage is La Nacional's
own food.

Until the files exist, the hero shows its designed gradient fallback
(green/amber), and the video fades in only after real frames decode.
